# xpairk-supply-watch

Public feed consumed by the Xpairk × United Rentals demo page's "OEM Supply Watch" bar.

- `alerts.json` — latest run: new open-web availability and lead-time signals for 185 CFM compressors, light towers, and mobile generators near Chicago Southside / NW Indiana. Updated twice daily (6am and 1pm CT).
- Signals are public listings (dealer pages, marketplaces, auctions, OEM/trade press). They are leads to verify, not confirmed inventory. No personal data.
